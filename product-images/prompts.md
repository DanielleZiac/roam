# Roam product image prompts
```
Everything was generated using Gemini's ___ model.

### Follow-up prompt: side view
```
Use the attached image as the reference. Show exactly the same product, with the same shape, parts, materials and colours, photographed from a straight side view at the product's own height. Do not add, remove or redesign any part. Clean studio product photography, seamless pure white background, soft even lighting, gentle natural shadow, sharp focus, photorealistic, square format, no text, no logos.
```

### Follow-up prompt: close-up
```
Use the attached image as the reference. Show exactly the same product, with the same shape, parts, materials and colours, as a close-up of its most important detail: the part a person touches or adjusts (handle, button, dial, clamp, grip or wheel hub). Slight angle from above, shallow depth of field. Do not add, remove or redesign any part. Clean studio product photography, seamless pure white background, soft even lighting, gentle natural shadow, sharp focus, photorealistic, square format
```

### Starting from a stock photo
For products that already have a lifestyle photo in this folder (for example `roam-ring-mouse-1.jpg`), you can upload that photo as the reference with the product's main prompt and add this sentence at the start:
```
Use the attached photo only as a guide to the product's shape and proportions. Remove the person, the hands and the background.
```
