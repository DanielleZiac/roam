# Roam product image prompts

One main prompt per product, plus two short follow-up prompts that give you extra angles of the same product. Each prompt is complete, so copy the whole block into your image tool.

## Settings to use every time
- **Shape:** square (1:1), at least 2048 × 2048 px. Shopify shows square product images most cleanly.
- **Save as:** the filename listed above each prompt, in this `product-images/` folder. Extra angles are `-studio-2.jpg` and `-studio-3.jpg`.
- **Keep the look consistent:** every prompt ends with the same style sentence. If you edit it, edit it in all of them.

## How to get 3 photos of one product
1. **Main shot:** paste the product's prompt below. Save the result as `<name>-studio-1.jpg`.
2. **Second angle:** upload the main shot you just made as a reference image, then paste the "Side view" follow-up prompt. Save as `<name>-studio-2.jpg`.
3. **Third angle:** upload the main shot again, then paste the "Close-up" follow-up prompt. Save as `<name>-studio-3.jpg`.

Always go back to the main shot as the reference. If you use the second image as the reference for the third, small changes pile up and the product drifts.

### Follow-up prompt: side view
```
Use the attached image as the reference. Show exactly the same product, with the same shape, parts, materials and colours, photographed from a straight side view at the product's own height. Do not add, remove or redesign any part. Clean studio product photography, seamless pure white background, soft even lighting, gentle natural shadow, sharp focus, photorealistic, square format, no text, no logos, no people.
```

### Follow-up prompt: close-up
```
Use the attached image as the reference. Show exactly the same product, with the same shape, parts, materials and colours, as a close-up of its most important detail: the part a person touches or adjusts (handle, button, dial, clamp, grip or wheel hub). Slight angle from above, shallow depth of field. Do not add, remove or redesign any part. Clean studio product photography, seamless pure white background, soft even lighting, gentle natural shadow, sharp focus, photorealistic, square format, no text, no logos, no people.
```

### Starting from a stock photo
For products that already have a lifestyle photo in this folder (for example `roam-ring-mouse-1.jpg`), you can upload that photo as the reference with the product's main prompt and add this sentence at the start:
```
Use the attached photo only as a guide to the product's shape and proportions. Remove the person, the hands and the background.
```

## Before you accept an image
- No readable text, logos, or brand names (AI text comes out garbled).
- No people or hands.
- The product looks physically plausible: wheels are round, the right number of legs, buttons in a sensible grid.
- The background is the same plain white as your other shots.

The alt text under each prompt is a draft. Adjust it to describe the image you actually end up with.
