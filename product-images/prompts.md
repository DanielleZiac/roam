# Roam product image prompts

One prompt per product. Each prompt is complete, so copy the whole block into your image tool.

## Settings to use every time
- **Shape:** square (1:1), at least 2048 × 2048 px. Shopify shows square product images most cleanly.
- **Save as:** the filename listed above each prompt, in this `product-images/` folder.
- **Keep the look consistent:** every prompt ends with the same style sentence. If you edit it, edit it in all of them.

## Before you accept an image
- No readable text, logos, or brand names (AI text comes out garbled).
- No people or hands.
- The product looks physically plausible: wheels are round, the right number of legs, buttons in a sensible grid.
- The background is the same warm sand as your other shots.

The alt text under each prompt is a draft. Adjust it to describe the image you actually end up with.
